What is captured? Key codes, normalized pointer positions, changed gamepad samples, your seed, and checkpoints you add.

What is not? Typed text, video, DOM content, identity, cookies, or network traffic.

You are offline. Good news: recording, import, and replay still work. The library never needs a server.

Wire it into your game loop.

recorder.ts
import { createRecorder, downloadCapsule } from '@sociobot/replay-capsule'

const recorder = createRecorder({
  seed: world.seed,
  target: game.canvas,
  maxBytes: 128_000
})

reportButton.onclick = () => recorder.start()
recorder.checkpoint('level-loaded', { level: 7 })
downloadCapsule(recorder.export())
