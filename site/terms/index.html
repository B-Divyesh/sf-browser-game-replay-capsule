Replay Capsule is free, open-source software for debugging browser games.

No warranty

The software and documentation are provided “as is,” without warranty. Deterministic replay depends on your game using its supplied seed consistently and avoiding state outside the capsule.

Responsible use

Use clear opt-in before recording. Do not adapt the library to capture typed text, secrets, or input outside the game context. Follow the laws and platform rules that apply to your game.

Availability

The hosted documentation and demo may change or be unavailable. The package has no hosted-service dependency and continues to work locally.

Contact

For questions, open an issue in the project’s public GitHub repository.
