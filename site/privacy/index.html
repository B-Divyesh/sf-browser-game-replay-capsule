Policy / 2026-08-30

Privacy for Replay Capsule.

Replay Capsule records only after a person starts recording. The library makes no network requests and includes no analytics or tracking.

What the library records

The library can record key codes, normalized pointer positions, changed gamepad samples, timing, a developer-supplied seed, and developer-supplied checkpoints. It ignores text fields, textareas, selects, and editable content.

Where replay data goes

A capsule remains in the current browser tab until it is downloaded. Replay Capsule does not upload, persist, sell, or share capsule data. A game developer who integrates the library controls any separate collection.

The sample demo

The demo uses a sample capsule held only in memory. It uses no cookies, browser storage, telemetry, advertising, or third-party runtime services. Leaving or reloading the demo discards the sample state.

Your control

Downloaded capsules can be deleted like any local file. Do not include secrets or personal information in developer-supplied seeds or checkpoints.

Contact

For privacy questions, open an issue in the project’s public GitHub repository.
