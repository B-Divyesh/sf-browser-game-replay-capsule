What the library does

Keep the bug report small and private.

⌁

Use your game adapter

Apply normalized inputs in your game. The library does not send synthetic DOM events or require an engine.

◉

Stay inside the byte cap

The recorder stops before it crosses the configured cap. Capped files stay small enough to share.

↺

Control replay timing

Replay at normal speed or faster. Pause, resume, and stop are available in the public API.

Install the library

Add replay capture to your game loop.

recorder.ts
import { createRecorder, downloadCapsule } from '@sociobot/replay-capsule'

const recorder = createRecorder({
  seed: world.seed,
  target: game.canvas,
  maxBytes: 128_000
})

reportButton.onclick = () => recorder.start()
recorder.checkpoint('level-loaded', { level: 7 })
downloadCapsule(recorder.export())
